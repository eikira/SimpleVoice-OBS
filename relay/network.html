Firewall: when the relay starts on a network address it makes one short connection attempt from that address to the gateway of that network, so your firewall (Windows Firewall, simplewall and others) can ask about this program. Allow it for your private network. If no question appears, check your firewall's list of allowed programs. To test: use Detect relay in the extension from the other PC.

There is no password. Anyone on the same network can send commands to this relay if they know your OBS ID. Use it only on a network you trust.
